# Telegram-бот для приёма заявок и записи клиентов

Бот на **aiogram 3.x** для студии/сервиса: клиенты смотрят услуги и цены, контакты, и
оформляют заявку на запись в несколько шагов. Все заявки сохраняются в локальную базу
SQLite, а администратор получает уведомление о каждой новой заявке.

## Что умеет бот

- **Главное меню** (`/start`) с кнопками:
  - 📝 Оставить заявку
  - 💰 Услуги и цены
  - 📍 Контакты
- **Запись на услугу** — пошаговый диалог (FSM) из 4 шагов:
  1. Выбор услуги из списка;
  2. Ввод имени;
  3. Номер телефона (текстом или кнопкой «Поделиться контактом»);
  4. Удобная дата/время или комментарий.
- На каждом шаге есть кнопка **«❌ Отмена»**, которая сбрасывает заполнение и возвращает
  в главное меню.
- После заполнения — сводка заявки и выбор: **✅ Подтвердить** или **🔄 Заполнить заново**.
- При подтверждении:
  - заявка сохраняется в базу данных SQLite;
  - клиент получает сообщение «заявка принята»;
  - администратору приходит уведомление со всеми данными клиента и ссылкой на его
    Telegram-профиль.
- **Команда `/admin`** (доступна только администратору) — показывает последние
  10 заявок из базы данных.
- Бот устойчив к некорректному вводу: проверяет имя, телефон и комментарий, просит
  ввести данные ещё раз при ошибке, и не падает при сбоях в базе данных или при
  недоступности администратора.

## Структура проекта

## Установка и запуск

### 1. Требования

- Python **3.10** или новее;
- Telegram-аккаунт для создания бота.

### 2. Получение токена бота и ID администратора

1. Откройте в Telegram бота **@BotFather**, отправьте `/newbot` и следуйте
   инструкциям — в конце вы получите **BOT_TOKEN** (строка вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).
2. Узнайте свой Telegram ID — например, через бота **@userinfobot**
   (отправьте ему `/start`, он пришлёт ваш числовой ID). Это и есть **ADMIN_ID**.

### 3. Настройка проекта

1. Скопируйте файл `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
2. Откройте `.env` и впишите свои значения:
   ```
   BOT_TOKEN=полученный_токен_от_BotFather
   ADMIN_ID=ваш_числовой_telegram_id
   ```

### 4. Создание виртуального окружения и установка зависимостей

См. раздел «Команды для терминала» ниже — там всё по шагам.

### 5. Запуск

```
python main.py
```

При первом запуске автоматически создастся файл базы данных `requests.db` с таблицей
`requests`. Бот начнёт отвечать в Telegram — найдите его по имени, которое вы указали
при создании в BotFather, и отправьте `/start`.

### 6. Проверка работы администратора

Отправьте боту `/admin` от аккаунта с ID, указанным в `ADMIN_ID` — появится список
последних 10 заявок (или сообщение, что заявок пока нет).

## Настройка под свою студию

- Список и названия услуг — переменная `SERVICES` в файле `keyboards.py`.
- Тексты «Услуги и цены» и «Контакты» — переменные `SERVICES_TEXT` и `CONTACTS_TEXT`
  в начале файла `handlers.py`.
- Приветственный текст — переменная `WELCOME_TEXT` там же.

## Частые вопросы

**Бот не отвечает после запуска.**
Проверьте, что в `.env` указан верный `BOT_TOKEN` и что компьютер/сервер имеет доступ
в интернет к серверам Telegram.

**Команда `/admin` ничего не делает.**
Убедитесь, что вы пишете боту именно с того Telegram-аккаунта, чей числовой ID указан
в `ADMIN_ID`.

**Как посмотреть базу данных напрямую.**
Файл `requests.db` — обычная база SQLite, её можно открыть, например, бесплатной
программой **DB Browser for SQLite**.
